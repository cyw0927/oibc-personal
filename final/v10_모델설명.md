## 1. 파이프라인

```
[제공 예보 A·B + 맥락·태양기하] ─┬─► 발전소 모델 E   (+ 시간별 GFS 박스 13개) ─┐
[시간별 GFS 박스 (gx_*)]  ───────┤                                             │ 그룹 합산(배정 1e42864d)
                                 ├─► 발전소 모델 B21 (+ 시간별 GFS 박스 13개) ─┤
                                 └─► 그룹 모델 H1    (v9와 동일)              ─┤
                                                                               ▼
                                     base = 0.35·E_gx + 0.35·B21_gx + 0.30·H1
                                                                               │
[제공 예보 하루 요약 + ECMWF·GFS 박스(v9 9개) + GFS 다변수 하루 요약 26개]
   ─► 하루 총량 모델 ×4 (2023판·2021판 × 시드 0·1) → 그룹-일 비율 rd
                                                                               ▼
                                     v10 = base × (1 + 0.5·(rd − 1))
```

E·B21·H1의 하이퍼파라미터, 학습 기간, 혼합 비율, α, 배정은 모두 v9와 같다. 바뀐 것은 입력 피처뿐이다.
