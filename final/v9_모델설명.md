## 1. 전체 파이프라인

```
[제공 예보 A·B (10시·17시 라운드)] ──┐
                                      ├─► 발전소 모델 E   (LightGBM L1, 2023-06~) ─┐
[발전소 메타·태양기하·맥락 피처]  ────┤                                            │ 그룹 합산(새 배정)
                                      ├─► 발전소 모델 B21 (LightGBM L1, 2021~)  ───┤
                                      └─► 그룹 모델 H1    (HistGB L1, 새 배정 재학습) ┤
                                                                                    ▼
                                         v4b_comp = 0.35·E + 0.35·B21 + 0.30·H1  (그룹-시각)
                                                                                    │
[제공 예보 하루 요약 + 외부예보 박스평균] ─► 하루 총량 모델 ×4 (2023판·2021판 × 시드 0·1)
                                           → 그룹-일 비율 rd (4개 평균)              │
                                                                                    ▼
                                         v9 = v4b_comp × (1 + 0.5·(rd − 1)),  0 이상으로 자름
```

- v7과 v9의 차이는 **하루 총량 모델의 입력 9개(외부예보)뿐**이다.
- E, B21, H1, 혼합 비율, 배정, α는 v7과 같다. v7 절차는 바이트 단위로 재현했다(7e1bbe90).

## 2. 구성 요소

### 2.1 공통 입력 (대회 제공 데이터만)
- 예보 A(관측소 61곳)
  - 운량, 기온, 습도, 강수, 풍속, 지면기압, 적설
- 예보 B
  - 운량, 기온, 상대습도, 자외선, 강수확률, 총수액량, 시정, 풍속, 이슬점, 운고, 적설
- 라운드 10·17(모두 D−1 17:00 이전 발행)
  - 두 라운드 행을 쌓아 학습한다(라운드도 피처).
  - 예측은 두 라운드의 평균이다.
- 맥락 피처: `site_features.py`에서 만든다.
  - ±1·±2시간 이동값
  - 대상일 08~17시 평균·최소·최대
  - 전날 대상일 평균(하루 전 발행분)
  - 전 관측소 지역 평균(시각별, 일별)
- 태양기하
  - 시간 구간 평균 cos(천정각)·고도. 우측닫힘 시각이며 −50/−30/−10분 표본을 쓴다.
  - 계절 sin/cos, 시각
- 맑은 하늘 지수: cs_wa, cs_wb = cosz·e0·(1 − 0.75·운량^3.4)
- 발전소 메타: 용량, 위도, 경도, 발전소 번호
- 목표
  - 발전소 모델: 이용률 cf = 발전량 ÷ 용량, [0, 1.2]로 자름
  - 손실: L1(중앙값 추정, 절대오차 채점과 일치)

### 2.2 발전소 모델 E
- 학습: 2023-06 ~ 2025-05-31(평가 시작 전까지), 태양고도 > 0인 행만
- LightGBM L1
  - 트리 2,000, 학습률 0.03, 잎 255, min_child 100
  - subsample 0.8, colsample 0.8
  - 시드 0·1 평균
- 출력: 발전소별 kWh. 그룹 합은 새 배정 기준이다.

### 2.3 발전소 모델 B21
- 학습: 2021-01 ~ 2025-05-31
- LightGBM L1
  - 트리 800, 학습률 0.05, 잎 127, min_child 200
  - subsample 0.8, colsample 0.8
  - 시드 0·1
- 피처는 E와 같은 전체 피처다.

### 2.4 그룹 모델 H1
- HistGradientBoosting L1
  - 그룹 피처 40개: 그룹 용량 가중 예보 요약
  - 하루 맥락 피처 70개
- 새 배정으로 다시 학습했다(`final_h1.py`).
  - 기준 배정으로 재실행하면 v4b H1과 최대 차이 2.9e−6 kWh로 재현된다.
  - 12개월 CV: 203.26 → 200.67M

### 2.5 혼합 v4b_comp
- 0.35·E + 0.35·B21 + 0.30·H1
- 12개월에서 비율을 재조정하는 실험도 했다(한 달 빼고 선택 시 −0.01%). 기존 비율이 거의 최적이라 그대로 둔다.

### 2.6 하루 총량 모델 (Gala et al. 2016 구조) — v9에서 변경된 부분
- 단위: 발전소-일. 목표 kd = 일 발전량 ÷ (용량 × 낮 시간 Σcosz), [0, 1.5]
  - 결측 없는 완전한 날만 학습한다.
  - 가중치는 용량 × Σcosz이다.
- 기존 피처(166개)
  - 낮 시간 cosz 가중 평균: 18개 예보 변수
  - 11~15시 운량 최대·최소
  - 라운드 17 값, 라운드 10 값, 그 차이(17 − 10, 예보 수정량)
  - 대상일 08~17시 시간별 패턴: 운량 A·B, 자외선, 강수확률, cs_wa
  - 맥락 상수, 계절, Σcosz
- **v9 추가 피처(9개, 외부 공개 예보, 고정 박스 평균)**

| 피처 | 출처 | 정의 |
|---|---|---|
| ec_box, ec_boxN, ec_boxS | ECMWF IFS open data (CC BY 4.0) | 12Z D−2 실행, ssrd(+42h − +36h)/21600 = **대상일 09~15 KST 평균 일사(W/m²)** |
| gf_dsw, gf_dswN, gf_dswS | NOAA GFS 0.25° (퍼블릭 도메인) | 00Z D−1 실행, f030 DSWRF 24~30h 평균 = **대상일 09~15 KST 평균 일사** |
| gf_tcc, gf_tccN, gf_tccS | NOAA GFS 0.25° | 같은 실행·구간의 TCDC(전운량, %) |

- 박스 정의
  - 전체: 북위 34~38°, 동경 126~130°
  - 북: 북위 36~38°, 남: 북위 34~36°(경도 같음)
  - 각 박스 안 격자 전체의 단순 평균이다. **발전소 좌표는 쓰지 않는다.**
  - 날짜로만 결합하므로 모든 발전소가 같은 값을 받는다.
- 기간
  - GFS: 2021-01-02 ~ 2026-05-31(1,974일, 실패 2일)
  - ECMWF ssrd: 2024-03-07 ~ (open data에 ssrd가 2024-03 초부터 공개됨)
  - 이전 기간은 결측(NaN)이며, LightGBM이 결측 분기로 처리한다.
- 모델: LightGBM L1
  - 트리 1,500, 학습률 0.03, 잎 63, min_child 50, colsample 0.7
  - 시드 0·1
  - 2023-06판(day23)과 2021판(day21) 두 종류
- 비율 계산
  - 각 모델: 발전소 비율 = 하루 예측 ÷ 시간별 B 예측의 일합, [0.2, 5]로 자른다.
  - 그룹-일 비율 = Σ(B × 비율) ÷ ΣB
  - rd = 4개 모델 비율의 평균(2023판·2021판 × 시드 0·1)
  - **최종 = v4b_comp × (1 + 0.5 × (rd − 1))**, α = 0.5

### 2.7 그룹 배정(v7부터 동일)
- 학습 기간(2024-06 ~ 2025-05) B21 발전소 OOF 오차로 정한다. 두 그룹 벌점 합이 가장 많이 줄도록 발전소를 하나씩 옮기는 탐욕 탐색이다.
- 결과
  - 81곳 이동
  - G1 121곳 20,028.010 kW / G2 132곳 22,627.360 kW (둘 다 20 MW 이상)
- 예측을 고정한 채 재배정할 여지는 이론 최대 0.93M, 실제 0.02M이다. 거의 한계까지 왔다.

## 4. 외부 데이터 사용 근거와 시점 규칙

- **근거:** 2026-10-28 공지 「외부 소스 이용 안내」 §1. 무료로 공개되고 상업 이용이 가능하며 같은 주소에서 누구나 다시 받을 수 있는 외부 데이터는 허용된다.
  - ECMWF open data: CC BY 4.0, AWS `ecmwf-forecasts`
  - NOAA GFS: 퍼블릭 도메인, AWS `noaa-gfs-bdp-pds`
  - 같은 URL에서 원본을 다시 받아 값이 일치함을 확인했다.
- **§5 준수:** 발전소별 격자나 최근접 매칭은 하지 않는다. 고정 광역 박스 평균만 쓴다(Codex가 코드를 검토해 확인).
- **시점(D−1 17:00 KST):**
  - ECMWF 12Z D−2 실행: 평가 기간 AWS 객체가 D−1 04:34~05:34 KST에 올라왔다.
  - GFS 00Z D−1 실행: 평가 기간 표본이 D−1 12:43~12:58 KST에 올라왔다.
  - 둘 다 마감 전이다.
  - 학습 기간 2025-02-26 ECMWF +36h 객체의 AWS 수정 시각은 D−1 20:56이다. 재게시로 보이며 학습 자료일 뿐이다. 평가 기간 예측 입력에는 영향이 없다.
- **누수 없음:**
  - CV: 하루 모델은 평가 월 첫날 이전의 완전한 날로만 학습한다.
  - 최종: 2025-06-01 이전 자료로만 학습하고, 평가 테이블에서 실적을 제거한다.
  - 외부 피처는 같은 날짜로만 결합하고, 평가 기간 전체 통계는 쓰지 않는다.
- 공개 기본 규정에 남은 "외부 데이터 금지" 문구와 10/28 공지가 충돌하는 점은 기록으로 남긴다. 10/28 공지가 외부 데이터에 관해 "현재 기준"이라고 스스로 밝히고 있다.
