# #1314 태양 높이 정규화 모델 탐색

실행 전 설계: 바구니 시간별 발전량을 직접 학습하는 대신, 태양 높이(`cosz`)에 따른 일조 시간 변화를 제거한 발전률을 학습한다. 기존 동일 기간 그룹 발전율 `energy/cap_avail`을 `max(cosz, 0.1)`로 나눈 값을 목표로 삼고, HGB L1 3설정을 합쳐 예측한다. 학습 가중치는 기존 `coverage × SMP × k`에 위 태양 높이 척도를 곱한다. 예측 시 다시 태양 높이를 곱하고 발전률을 0~1로 제한하며 해가 없는 시간은 0이다. 예측 시 실제 SMP는 입력에 사용하지 않는다. `0.1`은 지평선 가까이에서 나눗셈이 폭주하지 않도록 실험 전에 정한 고정값이며 DEV별 탐색을 하지 않는다.

발전소별 기존 FS2+L1 OOF 40%와 새 직접 그룹 모델 60%를 합쳐 #1314 v2와 동일한 그룹·시각·실적·SMP·k 조건에서 비교한다. 잠금 기간을 포함한 row group을 읽기 전에 차단한다. 계절과 지역 모델링을 개선할 가능성을 보는 탐색이며 보장된 개선이 아니다. 7·10월은 이미 반복 사용한 부분 코호트 DEV로 독립 테스트가 아니다. 예보 발행 및 수신 시점은 별도 검증이 필요하다. 평가 시점 실측, SMP 및 잠금 데이터는 학습·예측에 넣지 않는다. 결과 파생물은 Git 금지.
