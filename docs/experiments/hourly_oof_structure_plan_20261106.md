# #1314 시간대별 OOF 오차 구조 실험

자료 확장 전후 1월과 2월 직접 모델의 결과를 동일 그룹·시각으로 비교한다. 벌점 차이 및 SMP×k 가중 평균 오차, 11~15시 기여액, 그룹별 차이를 기록한다. 평균 오차는 예측−실적이며 원인에 대한 상관 진단이지 반사실 인과 판정은 아니다.

별도 구조로 바탕 FS2+L1 그룹 예측만 사용하고, 이전 기간 OOF의 `(실적−바탕 예측)/용량`을 그룹과 시간별로 나눈 뒤 과거 SMP×k×용량 가중 중앙값을 더한다. 시간별로 한 개의 값만 학습하므로 겨울 외 기온에 다항식이나 트리 응답을 외삽하지 않는다. 이는 그룹별 조건부 잔차 보정이며 새 40:60 혼합이나 비율 탐색이 아니다. 음수 예측은 0, 용량 초과는 용량으로 제한하며 야간은 0으로 둔다. 학습 자료가 없는 시간·그룹은 보정 없이 바탕 예측을 사용한다.

과거 MAY/JUL/AUG/SEP/OCT OOF로 JAN을, JAN을 추가해 FEB를 평가한다. 생성된 MAY/AUG의 SHA·cutoff·시드, 각 parquet 잠금 row group 여부, 중복키 및 평가에 쓰는 기존 #1314 기준의 실적·시간·SMP·용량 일치를 확인한다. 고정 설정 한 번만 실행하며 README 잠정(D05 HOLD), official_S=null. 겨울 기준은 원본 v2가 아닌 재학습 결과, 평가월 반복 사용, OOF 과거 생성 출처 및 예보 실제 수신시각 미확인, 과거 겨울 feature 생성 때 잠금 혼합 row group 접근 가능성은 별도 한계다. 잠금 데이터 및 잠금과 교차한 row group은 이번 실행에서 읽지 않는다. 데이터·예측 Git 금지.
