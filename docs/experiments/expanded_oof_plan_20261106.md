# #1314 과거 OOF 확장 계획

FS2+L1 바탕 모델을 2024년 5월과 8월에 대해 각각 재학습해 발전소별 out-of-fold 예측을 추가한다. 학습은 각 대상 달의 전날 00:00 KST까지이며 2023-06-01 01:00부터 시작, 예측 시드는 11/22/33 고정 평균이다. 각 월의 검증 기간 전체에 기록이 있는 발전소 코호트를 후향적으로 사용한다. 이 코호트는 모든 발전소를 대표하지 않는다. 대상 기간의 실적은 평가와 새 모델의 이후 기간 학습에만 쓴다.

이전의 JUL/SEP/OCT OOF에 MAY/AUG OOF를 더해 기존 `group_oof_direct.py`의 구조와 설정을 바꾸지 않고 1월에서 비교한다. 2월에서는 동일한 과거 OOF에 1월 OOF까지 추가한다. 평가 기간 실제·SMP를 모델 입력으로 넣지 않는다. 기준 #1314는 동일 키·실적·SMP·용량의 기존 재학습 예측이다. 기존 결과와 동일하게 README 잠정(D05 HOLD), official_S=null이다.

모든 parquet row group 메타데이터를 먼저 확인해 잠금 구간과 교차하면 중단한다. 잠금 원본과 혼합 row group은 이번 실행에서 열지 않는다. 다만 겨울 특성은 과거 생성 당시 잠금 혼합 row group을 열었을 가능성이 있다. 기존 7월 재현 결과는 예측 차이 0. 1·2월은 이미 반복 사용된 DEV이고 1차 OOF/데이터 출처 및 예보 실제 수신 시각의 완전 검증이 끝나지 않았으므로 독립 성능이나 공식 수익으로 주장하지 않는다. 데이터/예측 산출물은 Git에 올리지 않는다.
