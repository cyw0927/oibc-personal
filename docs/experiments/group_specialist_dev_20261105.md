# #1314 바구니별 전문 예측 실험

실행 전 설계: 기존 #1314의 단일 그룹 직접 예측 모델을 G1 전용과 G2 전용 모델로 분리해 각 바구니의 태양·날씨 반응을 따로 학습한다. 각 전용 모델은 기존 HGB L1 3설정 평균을 사용하며, 훈련은 fold 시작 전까지만, 용량 커버리지 30% 이상·낮 시간 자료로 제한한다. 각 행의 역사적 SMP × k × 커버리지를 가중치로 사용한다. 예측 시점의 실제 SMP·발전량은 입력에 사용하지 않는다.

최종 비교는 기존과 같은 0.4 × FS2+L1 발전소 예측 합 + 0.6 × 그룹 직접 예측을 사용하며 혼합비율을 탐색하지 않는다. 7월·10월 v2 #1314 OOF의 동일한 시각·그룹·발전소·실적·SMP·k와 대조한다. 이 구간들은 이미 반복 검토된 DEV이므로 탐색 결과이며 독립 검증이 아니다. 각각 224·252개 발전소인 부분 코호트다. 예보 발행·수신 시각은 별도 검증이 필요하다. 잠금 기간과 교차하는 parquet row group은 읽기 전에 차단한다. 생성 데이터는 Git 금지.

가중치는 학습 때 과거 실적에 해당하는 역사적 SMP로 계산한다. 실제 평가 시점 SMP는 모델 입력에 주지 않으며 사후 동일 조건 지표 계산에만 사용한다. 종속 바탕 예측 FS2+L1은 외부 팀 기존 OOF이므로 새 모델은 완전한 독립 예측 모델이 아니다.
