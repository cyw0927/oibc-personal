# #1314 겨울 v2 재학습 및 태양 높이 모델 비교

실행 전 계획. 기존 `feat_v2/group_features_train.parquet`의 모든 row group이 잠금 시작 전 끝남을 메타데이터로 확인하고 사용한다. 이 파일에는 2024-12~2025-02 그룹 특성이 있다. 원천 전처리 코드는 이전에 원본의 잠금 기간과 섞인 row group을 열어 행 필터를 적용했을 수 있다. 따라서 **이번 실행에서 잠금 row group은 열지 않지만, 특성 파일의 과거 생성 자체가 잠금 row group에 접근하지 않았다고 보증할 수 없다.** 특성 행의 최대 시각은 2025-03-01 00:00 KST다.

기존 안전 특성에 포함된 공통 시각 24,912행에서 실수 피처를 소수 6자리 반올림해 비교하면 차이 0이다. 1·2월 OOF의 발전소별 실제 발전량·용량을 그룹으로 합산했을 때 특성 파일의 실적·용량과 2,736개 그룹×시각에서 일치했다. OOF는 JAN 720시간, FEB 648시간, 각 253곳이며 검증에서 각각 1월 31일과 2월 28일 대상일은 제외된 기존 fold다.

기존 #1314 v2의 3개 HGB L1 구성·SMP×k×coverage 가중치와 동일한 설정으로 학습하며 40:60 결합을 유지한다. 1월 학습 cutoff는 2024-12-31 00:00, 2월은 2025-01-31 00:00 KST다. 역사 SMP는 잠금 시작 전에 멈추는 별도 연속 시간 파일을 사용한다. 비교 모델은 기존 태양 높이 정규화 방식과 동일한 목표·가중·3설정을 사용한다. FS2+L1 사이트 OOF, 키·실적·용량·SMP 및 cutoff를 동일하게 맞춘다. 검증 실적과 평가 시점 SMP는 사후 점수 계산에만 사용한다. 비율 탐색 없음.

기존 v2 저장 OOF가 있는 JUL/OCT도 같은 설정으로 재실행하여 기존 산출물과 대조한다. JAN/FEB의 원래 v2 OOF가 없으므로 기존 저장 결과와 완전 일치를 검증할 수 없어 재학습 결과를 '원본 v2 비트 단위 재현'이라고 단정하지 않는다. 예보 발행·수신 시점과 과거 데이터 생성의 독립 검토는 미완이다. 모든 산출물은 개발 탐색이며 README 잠정(D05 HOLD), official_S=null. JAN/FEB는 이미 개발에 사용된 구간이고 연간·공식 성능 검증이 아니다. 결과 데이터는 Git 금지.

## 데이터 분리 가능성

원본 parquet의 메타데이터만 확인했다. WA 예보 2024-12-06 19시 이후의 row group은 2025-06-01까지 포함하므로 1·2월과 잠금이 섞여 있다. WB 예보는 안전한 row group이 2025-02-12 20시까지이나, 그 이후 구간은 잠금과 섞여 있다. 발전량도 2024-11-07 12시 이후 필요 구간이 잠금 기간과 같은 row group이다. 따라서 원본으로부터 1·2월 완전 분리는 row group 단위 무열람 조건으로 불가능하다. 이전에 만든 잠금 이전 그룹 특성 파일을 대신 사용했다.
