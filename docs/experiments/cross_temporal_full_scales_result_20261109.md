# #1314 전체 시간 계층 시공간 조정 실험 결과

`cross_temporal_full_scales_plan_20261109.md`의 조건을 적용했다. 한 날의 1·2·3·4·6·8·12·24시간 구간을 모두 사용해 발전소 253곳과 그룹 G1/G2의 공간·시간 예측을 비음수 제약 아래 동시에 조정한다. 시간당 24개와 상위 시간 구간 36개, 각 계열당 60개 계층을 사용했다.

발전소별 2~24시간 예측은 선행 기간에 생성된 발전소별 FS2+L1 OOF와 실적으로 구간별 별도 pooled ridge를 훈련한다. 이는 **별도 모델 출력**이나 시간별 FS2+L1 예측을 입력으로 하므로 완전히 독립된 날씨 모델은 아니다. JAN의 발전소 일별 원예측 7,590개가 시간별 예측을 단순 평균한 값과 모두 달랐다. 그룹별 2~24시간 예측은 과거 날씨·실적으로 별도의 pooled ridge를 훈련한다. OCT 모델은 MAY/JUL/AUG 이전 OOF, JAN 모델은 그에 OCT, FEB 모델은 JAN까지 추가했다. 검증 기간의 실적과 SMP는 예측 입력에 사용하지 않았다.

OOF 오차로 255×255 공간과 60×60 시간 공분산을 각각 추정하고 데이터 기반 수축 후 Kronecker 곱으로 근사했다. OCT에서 이력이 없는 발전소 한 곳의 공간 분산은 같은 그룹 발전소들의 중앙값으로 대체했다. 조정은 발전소 시간 단위 값을 기본변수로 삼아 0 이상, 발전소 합=그룹, 시간 하위 합=상위 합을 동시에 만족한다. 기간별 계층은 수치 조건을 위해 평균으로 계산하고 저장·검증 때 실제 합계로 되돌렸다.
