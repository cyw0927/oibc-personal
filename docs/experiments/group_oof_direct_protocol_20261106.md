# #1314 대체: 과거 OOF 기반 직접 그룹 학습 계획

기존 40:60 결합 대신 FS2+L1 발전소 OOF를 그룹으로 합친 값을 입력 특성으로 제공하고, 모델이 그룹 실적/용량을 직접 예측한다. 과거 OOF의 그룹×시각별 1차 예측, 같은 시점에 이용 가능한 날씨·태양·시간·그룹 특성과 해당 실적만 학습한다. 2차 모델은 HGB 절대오차(300 iterations, learning rate 0.05, max_leaf_nodes 15, min_samples_leaf 100, l2=1, seed=0), 손실 가중치는 과거 SMP×k×코호트 용량이다. 예측 대상의 실적·SMP·발전량 lag는 모델 입력이 아니다. 밤에는 0, 출력 비율은 0~1로 제한한다. 결합비율 탐색 없음.

1월은 먼저 끝난 JUL/SEP/OCT OOF만 학습, 2월은 JUL/SEP/OCT/JAN OOF만 학습한다. SEP는 안전 자료로 직접 재학습한 FS2+L1이며 JUL/OCT/JAN은 기존 OOF다. SEP를 추가함에 따라 기존 OOF 보정 실험과 입력이 다르며 새로운 전체 직접 예측 모델이다. 각 학습 OOF의 원 예측 학습 cutoff와 메타데이터 출처는 별도 확인이 필요하다. 1·2월 #1314 기준은 원본 v2가 아닌 기존 동일설정 재학습 예측이다. 입력의 그룹·시각 중복, 잠금 row group, 학습-검증 시각 분리, 정상 값과 같은 실적·SMP·용량·키를 점검한다. DEV 반복 사용이며 원본 예보 실제 수신·겨울 특성의 과거 생성시 잠금 혼합 row group 접근 가능성은 미확인. 결과는 README 잠정(D05 HOLD), official_S=null, Git에 데이터·예측 저장 금지.
