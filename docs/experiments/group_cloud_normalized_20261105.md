# #1314 태양·구름 정규화 예측 실험

실행 전 설계. 그룹 특성의 구름 감쇠가 반영된 태양광 지표 `cs_ab`를 활용하여 그룹 발전률을 `max(cs_ab, 0.1)`로 나눈 뒤 단일 풀링 HGB L1 모델을 학습한다. 학습 가중치는 기존 coverage × 역사 SMP × k × 동일한 지표다. 예측은 배율을 다시 곱하고 발전률을 0~1 범위로 제한하며 해가 없는 시간에는 0이다. 0.1은 지평선 근처의 수치 폭주를 막기 위한 고정값이며 데이터나 평가 결과로 탐색하지 않는다. 예측 시 실제 SMP·발전량은 입력에 사용하지 않는다.

기존 #1314와 같은 FS2+L1 발전소별 예측의 합 40% + 새 그룹 모델 60%를 사용하며 비율 탐색은 금지한다. JUL/OCT는 #1314 v2 OOF의 발전소·시각·그룹·실적·SMP·k를 직접 대조한다. APR/AUG는 기존 #1314의 FS2+L1 OOF가 없으므로 동일한 독립 발전소 모델의 예측을 고정한 대리 비교다. APR은 174곳에 G1 17.907MW/G2 8.895MW로 20MW 조건 미충족, AUG는 250곳이다. 따라서 전체 발전소 및 공식 대회 성능으로 해석하지 않는다.

2024-04·07·08·10월은 모두 이전에 개발에 활용된 자료다. fold별 학습은 예측 구간 이전까지만, 평가 일자 전 실적·SMP를 사용한다. 잠금 기간을 포함하는 row group은 읽기 전에 차단한다. 예보 발행/수신 시각은 미검증이므로 제출에 사용하면 안 된다. 모든 결과는 README 잠정, D05 HOLD, official_S=null이다. 파생 데이터는 Git 금지.
