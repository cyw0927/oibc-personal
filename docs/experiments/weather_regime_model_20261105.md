# #1314 날씨별 선형 전문가 구조 탐색

대회 제공 README에 따르면 예측 시점은 대상일 전일 17시 KST이며 round=10과 17은 각각 대상일 전일 10시와 17시 발행으로 정의되어 있다. 명목상 둘 다 사용 가능하다. 다만 17시 발행이 17시 cutoff에 실제 도착했는지는 별도 수신 로그가 없어 미확인이다. 종전 `prep_group_features.py`는 두 회차를 평균하고 두 회차 차이도 사용하므로, 실제 발행/수신 지연이 있다면 입력 누수 위험이 있다. 17시 이전 실제 도착을 입증하기 전 제출 검증 완료라고 주장하지 않는다. 밤 00시 종료 구간의 날짜 해석 및 공급자 문서 대조도 별도 확인한다.

## 진단

반복 사용한 DEV의 결과를 회고적으로 분석했다. 7월 유사날씨 모델의 추가 벌점 1,009만원 중 11~15시가 약 863만원이며, WA 평균 구름 66 초과 구간이 약 885만원이다. 2월 추가 벌점 868만원 중 11~15시가 약 650만원이며, WA 평균 구름 33 이하 구간이 약 582만원이다. 시각·구름 분류는 겹치며 합산하면 안 된다. 구름은 예보의 집단 평균이고 인과관계는 증명하지 않는다. 벌점은 README 잠정(D05 HOLD), official_S=null이다.

## 추가 실험 계획 (실행 전 기록)

유사날씨 검색이나 HGB 대신 WA 평균 운량 33 이하·33 초과 66 이하·66 초과의 세 구간으로 구분해, 각 구간에 별도의 다항 Ridge 회귀를 학습한다. 태양고도·계절·온도·구름 등 예보 입력의 2차 상호작용을 사용한다. 과거 입력으로만 중앙값 보간과 표준화, 과거 SMP×k×관측 커버리지 가중 학습을 수행한다. 이 경계는 위 진단에서 사용한 기준이므로 동일 DEV 결과에 맞춘 탐색 설계이며 독립 사전 검증이 아니다. 하이퍼파라미터와 결합 비율은 추가 탐색하지 않는다. 동일한 바탕 OOF 40% + 새 그룹 예측 60% 및 단독 그룹 예측을 모두 보고한다.

JUL/OCT는 보관 v2, JAN/FEB는 v2 설정 재학습과 비교한다. 각 fold의 이전 시각만 학습하고 평가 실제 발전량·실제 SMP는 점수에만 쓴다. 기존에 사용한 잠금 이전 그룹 특성 파일만 사용하되 해당 파일은 과거 생성 시 잠금과 섞인 row group을 열었을 가능성이 있다. 이번 실행은 그 원본이나 잠금 행을 읽지 않는다. 결과는 학습 기간 중 다른 시각을 포함한 반복 DEV·부분 코호트이며 독립 성능이 아니다.
