# #1314 신경망 그룹 모델 실험 계획

기존 HGB 대신 완전연결 신경망(64, 32; ReLU; alpha 0.01; Adam; 최대 250 epoch; seed 42)으로 시간별 그룹 발전 비율을 직접 예측한다. 회귀 출력은 [0, 1]로 제한하고 야간을 0으로 처리한다. 결측 보완과 표준화는 검증 이전 학습 구간에서만 적합한다. 가중치는 기존 coverage × 과거 SMP × k다. 동일 FS2+L1 사이트 예측 40%와 새 그룹 예측 60%를 결합한다. 설정 및 비율 탐색은 하지 않는다.

JUL/OCT/JAN/FEB 각 평가 시작 이전 학습, 같은 발전소 코호트, 키, 실적, 용량, SMP, k, 참조 예측 및 지표를 검사한다. 결과는 README 잠정(D05 HOLD), official_S=null. 겨울 참조는 원본 v2 OOF가 아닌 재학습 결과다. 모든 기간이 반복 사용 DEV이므로 유리한 결과가 나와도 독립 검증·확실한 우월성을 주장할 수 없다. 원본 예보 수신시각과 과거 겨울 특성 생성 과정의 잠금 row group 접근 가능성은 미확인이다. 이번 실행에서 잠금 데이터 및 잠금 row group은 읽지 않는다. 결과 데이터는 Git 금지.
