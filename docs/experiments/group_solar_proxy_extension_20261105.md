# 태양 높이 정규화 4·8월 추가 진단

기존 JUL/OCT 태양 높이 정규화 모델의 프로토콜을 유지해 2024년 APR/AUG에 적용한다. 학습은 fold 이전, 입력은 동일한 안전 분리 파일이며 평가 구간의 실측·SMP를 학습에 사용하지 않는다. 기존 학습된 독립 발전소 예측을 양쪽에 동일하게 고정하고, 사전 등록된 0.4 사이트 + 0.6 그룹 비율을 사용한다.

두 기간의 FS2+L1 사이트 OOF가 없으므로 대리 비교이며 기존 #1314에 대한 직접 비교가 아니다. 이미 개발에 활용된 기간이다. APR 174곳·두 그룹 20MW 미달, AUG 250곳이다. README 잠정 D05 HOLD, official_S=null. 모델의 발행 시점과 겨울·연간 성능은 미확인이다. 잠금 row group은 읽기 전에 차단한다.

동일 키·실적·SMP·k, 0.4:0.6 결합, 벌점 재계산을 확인했다. 대리 모델의 개선으로 #1314가 개선됐다고 주장할 수 없다. 기존 직접 비교는 JUL -2.57%, OCT +0.91%로 엇갈린다. 다른 검증 구간, 완전한 발전소와 동등한 바탕 OOF 및 예보 가용성 증거가 필요하다.
