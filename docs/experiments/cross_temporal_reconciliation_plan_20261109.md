# #1314 시공간 동시 조정 실험 계획

Di Fonzo & Girolimetto (2023)의 식 (12)~(15)의 동시 계층 조정과 비음수 제약을 참고한다. 253개 발전소와 G1/G2, 각 시간(24개)과 하루 합계(1개)를 동시에 조정한다. 발전소 간 및 그룹의 과거 OOF 오차로 공간 공분산을, 하루 안 각 시각 및 하루 합계 오차로 시간 공분산을 추정하고 둘을 Kronecker 곱으로 묶어 수치 안정화를 적용한 가중최소제곱 목적을 사용한다. 시간별 발전소 예측을 기본변수로 두고 비음수 제약 아래 발전소 합=그룹, 시간별 합=하루 합을 동시에 강제한다.

독립 입력은 FS2+L1 발전소별 시간 OOF, 독립 그룹 시간 모델, 독립 그룹 하루 합계 모델이다. 발전소별 하루 입력은 시간별 원예측의 합으로 만들기 때문에 별도 일별 모델이 아니며, 이것이 추가 정보를 중복한 것으로 취급될 위험이 있다. 논문의 2·3·4·6·8·12시간 중간 시간 계층, 논문의 전체 공분산 추정법과 원래 자료·실험 설정을 그대로 구현하지 않으므로 **논문 전체 재현이 아닌 하루 단위 시공간 동시 조정 근사**다.

각 그룹 하루 모델은 해당 fold보다 과거의 완전한 일별 그룹 특성·발전량으로 별도 학습한다. 현재 sklearn 바이너리가 로드되지 않아 일별 모델은 학습 구간만으로 결측 중앙값 대체와 표준화를 한 ridge(정규화 강도 1)로 고정한다. OCT 예측을 과거 OOF로 만들어 JAN의 공분산을, OCT/JAN OOF를 사용해 FEB의 공분산을 추정한다. 연속성과 시간 단위의 축소된 상관행렬은 과거 OOF로만 정하고 축소 강도는 데이터에서 계산한다. OCT에서 기록이 없는 발전소는 수치적 양의 분산 하한을 적용한다. 평가 기간 실제·SMP는 예측에 넣지 않으며, 정산 비교에만 사용한다. #1314는 기존 동일한 FS2+L1 OOF, 그룹 직접 예측, 40:60 기준의 JAN/FEB 재학습 예측이다.

각 입력 parquet를 읽기 전에 모든 row group이 잠금 시작 전임을 메타데이터로 검사한다. 과거 겨울 group feature의 생성 당시 잠금 혼합 row group 접근 가능성, 실제 예보 수신시각, 겨울 원본 v2 미대조, 반복 DEV와 OCT 252개소는 한계다. 산출은 README 잠정(D05 HOLD), official_S=null, 대회 데이터·파생물은 Git 금지. 평가 결과로 모델 설정·결합비를 탐색하지 않는다.
