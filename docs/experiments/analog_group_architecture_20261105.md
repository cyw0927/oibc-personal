# #1314 대안: 유사 날씨 사례 검색 모델

## 실행 전 설계

기존 HGB의 나무 분할 대신 과거 데이터에서 같은 바구니·같은 시각에 태양 높이, 계절과 기상 예보가 비슷한 40개 사례를 찾아, 그때의 용량 대비 발전량의 가중 중앙값으로 직접 예측한다. 각 그룹·시각별 최근접 사례를 별도로 검색한다. 숫자 스케일은 학습 구간의 중앙값·사분위 범위로만 정하고, 누락값도 학습 구간 중앙값으로만 채운다. 미래 실제 발전량·발전량 lag·관측 기상·평가 시점 실제 SMP는 입력하지 않는다. 학습 기간 과거 SMP×k×관측 커버리지로 이웃들의 중앙값만 가중한다. 사전 자료 건수 점검에서 JUL G2 20시가 47개라 처음 제안했던 50개 대신 40개로 정했다. 평가 오차는 보지 않았으며 결과 전 40개와 입력 항목을 고정한다. 훈련 사례가 40개 미만이면 해당 fold는 실패시킨다.

FS2+L1 OOF 40%와 직접 그룹 예측 60%의 기존 결합비는 유지한다. 직접 사례 검색 단독도 함께 표시해 #1314 바탕 모델 의존도를 분리한다. JUL/OCT는 보관된 v2 그룹 예측과, JAN/FEB는 동일 조건으로 재학습한 v2 그룹 예측과 비교한다. 기존 OOF의 그룹·시각·발전소 범위·실제 발전량·SMP·k를 사용하며 학습은 각 fold 시작 전까지만 허용한다. 7월은 224곳, 10월은 252곳, 1·2월은 253곳이다. 7월은 부분 용량 20MW 미달; 겨울은 각 달의 기존 DEV 30일/27일만 포함한다.

잠금 이전 parquet row group만 읽고 안전하게 분리된 SMP를 사용한다. 겨울 그룹 특성 파일의 **과거 생성 과정은 잠금 기간이 섞인 원본 row group을 열었을 가능성**이 있다. 이 실험에서 해당 원본 또는 잠금 행은 읽지 않는다. 1·2월의 원래 v2 보관 결과는 없어 직접 일치 검증이 불가능하고, 예보 발행/수신 시각이 미확인이다. 4개 기간 모두 이전에 반복 사용한 DEV이므로 독립 검증 및 연간 성능을 의미하지 않는다. 정산은 README 잠정, D05 HOLD, official_S=null이다. 파생 데이터는 Git에 올리지 않는다.
