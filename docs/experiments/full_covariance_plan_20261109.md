# #1314 전체 시공간 공분산 및 수렴 검증 계획

기존 255개 공간 계열×60개 시간 계층의 원예측·과거 OOF를 그대로 사용한다. OCT 31일 또는 OCT+JAN 61일의 하루별 전체 15,300차원 오차 벡터에서 공간과 시간을 나누지 않는 전체 표본 공분산을 추정한다. 표본이 차원보다 훨씬 적어 표본 공분산은 역행렬이 없으므로, 비대각 공분산을 유지하면서 대각 행렬로 수축하는 계수를 과거 자료에서 계산하고 수치 안정을 위해 계수 하한 0.01을 둔다. 훈련 기간에 없는 발전소의 오차 분산은 같은 그룹의 시간 계층별 중앙값을 사용하고 해당 교차공분산은 0으로 둔다. 사용 가능한 OOF·예측 기간·전처리는 직전 실험과 같다.

전체 행렬을 저장하는 대신 대각 행렬+저랭크 표본 공분산을 Woodbury 공식으로 계산한다. 이는 지정한 수축 전체 공분산의 정확한 선형 연산이지 공간×시간 분리형 근사가 아니다. 비음수 및 발전소·그룹·모든 시간 계층의 일치 조건을 만족하도록 전 계층 GLS를 푼다. 목적함수 스케일을 정규화하고 종료 상태, KKT projected-gradient 절대값과 상대값을 남긴다. 작은 합성 예에서 직접 전체 행렬 역연산 및 독립적인 제약 최적화와 대조한다. 자동 종료만으로 정확한 최적해를 단정하지 않는다.

1월은 OCT OOF만, 2월은 OCT/JAN OOF로 공분산을 추정한다. 평가 대상 실적·SMP는 학습/조정에 넣지 않는다. 모델 선정·결합비 탐색 없음. 모든 입력 parquet row group은 읽기 전 잠금 시작 이전인지 검사한다. 이전 생성된 겨울 특성의 잠금 혼합 row group 접근 가능성·예보 수신 시각 미확인·겨울 원본 v2 OOF 미대조·반복 DEV라는 한계는 유지한다. README 잠정(D05 HOLD), official_S=null. 대회 데이터와 예측 Git 금지.
