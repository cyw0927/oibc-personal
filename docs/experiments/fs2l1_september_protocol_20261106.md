# #1314 2024년 9월 과거 재학습 비교 계획

FS2+L1 3-seed 재현이 기존 JUL 평균 예측과 일치하는지 먼저 확인한다. 일치가 검증되지 않으면 새 기간 결과는 재현 보류로 표시한다. 9월 그룹별 검증이 가능한 모든 시간에 실적이 있는 발전소만 코호트로 고정한다. 학습은 2023-06-01 01:00부터 2024-08-31 00:00 KST까지, 검증은 2024-09-01 01:00~2024-10-01 00:00다. 대상일 전날 17시 예보, 원본 FS2 R2 각 10/17 발행 예보에 대해 2개 모델, 시드 11/22/33, LightGBM L1 및 원본 클립·평균을 따른다. 모델은 fold 전체에서 고정한다.

동일 발전소·그룹·시각·실적·SMP·k를 이용해 바탕 FS2+L1 예측 40%는 고정하고, 나머지 60%를 기존 #1314 HGB 직접 예측과 기존에 구현한 태양 기초식+잔차 HGB로 각각 채운다. 가중치·설정은 각 모델 기존 구현 그대로 사용한다. 발전소군은 후향적 완전관측 코호트이며 두 그룹 20MW 제약을 별도로 보고한다. #1314는 원본 보관본이 아니라 같은 설정으로 해당 fold에서 재학습한 기준이다.

9월의 발전량 일부는 과거 10월 모델의 학습 기간에 포함됐다. 이미 여러 DEV 결과를 보고 후보를 만들었으므로 9월도 엄격한 독립 최종 테스트라고 부르지 않는다. 수치는 README 잠정(D05 HOLD), official_S=null이며 예보 실제 수신 시점 미검증. 저장된 결과는 대회 데이터 파생물이므로 Git에 올리지 않는다. 모든 parquet 입력은 row group 메타데이터를 읽고 잠금 구간에 닿으면 실제 읽기 전에 중단한다.
