# #1314 전체 시간 단위 시공간 조정 계획

하루 24시간에 대해 1·2·3·4·6·8·12·24시간의 중첩되지 않은 모든 구간(총 60개)을 생성한다. 발전소별 2~24시간 예측은 이전 시점 발전소 OOF의 해당 구간 예측과 실적을 이용해 별도의 pooled ridge 모델을 학습하여 생성한다. 발전소별 24시간도 단순 시간 합계가 아닌 별도 모델 출력이다. 그룹 2~24시간은 평가 이전 그룹 날씨 및 발전량을 이용한 별도 pooled ridge로 예측한다. 그룹별 시간별 예측은 기존 #1314 직접 그룹 모델의 OOF다. OOF 예측을 이용한 모델은 완전히 별도 원시 입력 모델이 아니므로 의존성이 크며 성능이 보장되지 않는다.

과거 OCT OOF와 OCT 이전 예측으로 JAN 검증, OCT/JAN OOF와 그 이전 예측으로 FEB 검증을 수행한다. 발전소 시간 집계 모델은 OCT용 MAY/JUL/AUG, JAN용 MAY/JUL/AUG/OCT, FEB용 MAY/JUL/AUG/OCT/JAN의 선행 OOF에서만 학습한다. 시간 집계 그룹 예측 모델은 해당 fold의 시점 이전 그룹 발전량·날씨 특성으로만 학습한다. 예측 대상 구간의 실적 및 SMP는 예측 입력이 아니며 동일 #1314 기준과 정산 비교에만 사용한다. MAY/AUG는 부분 코호트이며 월 단위 학습에서는 이미 반복 사용한 DEV의 누적 사용 한계가 있다.

예측 계층 전체를 동시에 조정하되 0 이상, 발전소 합=그룹, 상위 시간 합=하위 시간 합의 관계를 지킨다. 과거 OOF에서 발전소 간 및 시간 단위 간 오차 공분산을 추정하되 차원이 약 15,300이고 독립 일별 표본이 수십 일인 관계로 공간×시간 분리형 공분산 및 데이터 기반 수축을 사용한다. OCT 자료에 없는 발전소는 수치적 불안정을 피하도록 같은 그룹의 정규화 공간 분산 중앙값을 사용하고 교차공분산은 0으로 둔다. 2·3·4·6·8·12시간과 발전소별 별도 일별 모델까지 포함하지만 원 논문의 전 가정·전체 비분리 공분산을 그대로 재현한 것은 아니다. 임의 결합비 탐색 없음.

전 입력 parquet row group이 잠금 이전인지 메타데이터 검증 후에만 읽는다. 과거 생성된 겨울 특성의 잠금 혼합 row group 접근 가능성과 예보 실제 수신시각 미검증, 겨울 #1314 원본 v2 미대조, 반복 DEV, OCT 252개소는 한계다. 점수는 README 잠정(D05 HOLD), official_S=null, OOF 및 예측 데이터 Git 금지.
