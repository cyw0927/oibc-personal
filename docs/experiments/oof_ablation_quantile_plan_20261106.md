# #1314 과거 OOF 구성 영향과 선형 분위수 실험 계획

기존 확장 OOF HGB 모델의 설정·평가를 고정하고 MAY만 제거한 학습 및 AUG만 제거한 학습을 각각 다시 실행한다. JAN/FEB의 검증 행과 과거 JAN 추가 여부는 기존과 동일하다. 이는 해당 자료가 다른 달과 함께 있을 때의 영향이며, 학습량 변화나 변수 상호작용과 구분되는 단일 날씨 원인으로 단정하지 않는다. 검증 결과를 사용해 해당 월 제거 여부를 결정하지 않는다.

다른 구조는 FS2+L1 바탕 그룹 예측 및 달력·날씨를 입력으로 하는 가중 선형 중앙값 회귀다. 그룹 정산의 절대오차에 맞게 capacity-normalized target과 과거 SMP×k×capacity 가중치로 중앙값을 학습한다. 학습 데이터로만 중앙값 결측 처리 및 표준화, 정규화 강도 alpha=0.01 고정, 각 예측 범위 [0, capacity], 야간 0을 적용한다. 피처·설정·과거 기간을 고정하고 한 번만 실행한다. 대상 실적·대상 SMP·발전량 lag는 예측 입력이 아니다. FS2 바탕과 새 그룹 예측을 사후 결합하지 않는다.

MAY/JUL/AUG/SEP/OCT OOF로 JAN, JAN까지 추가해 FEB 평가. 두 실험 모두 재사용 DEV이며 겨울 #1314 비교 기준은 원본 미대조 재학습이다. 모든 입력 parquet row group이 잠금 시작 전인지 읽기 전에 확인한다. 겨울 특성 파일은 과거 생성시 잠금과 섞인 row group에 접근했을 가능성이 있고 실제 예보 수신 시각도 미확인이다. README 잠정(D05 HOLD), official_S=null. 대회 파생물은 Git 금지.
