# Independent Extra Trees group model experiment

Objective: try a fundamentally different model from the existing histogram gradient-boosted group ensemble. Fit one ExtraTreesRegressor from scratch to group-hour capacity factor, weighted by available capacity × historical SMP × k. Inputs: pre-lock participant-derived group weather/time features only; no observed weather, generation lags, future prices or external pretrained models. Model: 250 trees, max_features 0.8, min_samples_leaf 12, random_state 42, squared-error splitting. Clamp predicted factor to [0,1]. No parameters or blend weights are searched in this experiment.

Walk-forward cutoffs: 2024-06-30 00:00 for July, 2024-09-30 00:00 for October. Train only before cutoff; evaluate group outputs on the same site/time cohort and SMP/k as the existing #1314 40/60 FS2+L1 and group-direct comparison. Compare independently trained Extra Trees alone, not a blend. Actual #1314 comparison depends on existing team-derived FS2+L1 OOF; provenance/reuse permission remains unresolved.

Both months and cohorts have been inspected in previous experiments; treat this as exploratory, not blind or final evidence. July has 224 sites and October 252, not all 253; do not claim valid competition portfolio or annual revenue. Group features were precomputed for the full fixed mapping, whereas targets use available capacity; report the mismatch as a limitation.
