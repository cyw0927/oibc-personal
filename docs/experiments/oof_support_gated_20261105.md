# #1314 보정기 실패 원인과 범위 보호형 대안

## 원인 분석

기존 다항 Ridge 보정기 재학습 과정을 동일하게 재현해 7/10월 훈련과 1월 낮 검증 피처 범위를 대조했다. WA 평균 예보 기온은 훈련 9.886~34.217°C인데 1월 -8.404~9.827°C로 **낮 평가 행 100%가 훈련 최저보다 낮다**. WB 온도도 87.8%가 훈련 범위 밖이다. 날짜를 표현한 두 순환 값도 모두 이전 기간의 범위 밖이다. 다항 변환 후 표준화 변수의 절댓값 99백분위는 훈련 3.347 대 1월 15.142였다. 가장 큰 보정값에 기온·습도 및 계절 상호작용 항들이 크게 기여했다. 연관성은 분명하지만 개별 항 제거 반사실 실험은 하지 않았으므로 단일 원인으로 단정하지 않는다. 기존 보정은 1월 가중 순오차 +45.46%, 최대 변경 약 9,942kWh였다.

## 실행 전 확정 대안

훈련 범위 밖 온도에 기존 회귀식을 외삽하지 않도록 2단계 보정기를 바꾼다. 원래 #1314 예측을 고정한 상태에서, 같은 그룹의 과거 OOF 중 유사한 예보 40개를 찾아 **과거 잔차의 가중 중앙값**만큼 보정한다. 과거 기록 범위를 벗어나는 WA 또는 WB 기온, 결측 기온은 보정을 건너뛰고 기존 예측을 그대로 쓴다. 예측값에 실제 검증 실적·평가 SMP·발전량 lag는 넣지 않는다. 학습 OOF 가중치만 역사 SMP×k×용량을 사용한다. 유사도 정규화는 학습 구간에만 적합한다. 과거 잔차의 가중 중앙값은 이웃들의 값 범위를 벗어나지 않는다. 40개와 범위 점검 정책은 사후 진단을 바탕으로 고정했으며 별도의 반복 탐색은 하지 않는다. 수익 개선을 위한 결합비 탐색은 없다.

JAN은 JUL/OCT로, FEB는 JUL/OCT/JAN OOF로 학습하며 cutoff 검증. 입력·키·실적·SMP는 기존 검증과 같다. 과거 관측 결과로 설계한 탐색이므로 DEV에서 좋아져도 독립 테스트가 아니다. 원본 겨울 v2 예측과 원본 예보 수신시각 미확인. 이전에 생성된 잠금 전 그룹 특성은 과거 혼합 row group 접근 가능성이 있으며 이번 실행은 잠금 행이나 원본을 읽지 않는다. README 잠정, D05 HOLD, official_S=null. 데이터·파생물 Git 금지.
