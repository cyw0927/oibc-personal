## 시험 대상: 그룹 직접 예측 부분(최종식의 60%)

FS2+L1 발전소 모델(LightGBM)은 HOLDOUT 예측이 없고, 로컬에 LightGBM이 없어 재학습할 수 없다.
그래서 FS2+L1 부분은 기존 평가구간 예측(`prediction_test.csv` SHA 226b2bc9, 2025-02까지 학습)을 그대로 쓰고, 결합비율 0.4도 고정한다.

후보는 둘 다 HGB L1, 가중치 cov×k×SMP, 사전 등록된 3개 설정 평균(v0.2와 동일)이다.

- **H0:** v0.2 피처 40개. 5차 제출본과 같은 모델이다.
- **H1:** H0 + 하루 맥락 피처. 정의는 `scripts/oibc_1314/claude_1109/ctx_features.py`에 고정한다.
  - 변수 8개: wa_cloud, wb_cloud, cs_ab, wb_uv_idx, wb_precip_prob, wb_vis, wb_rel_hum, wa_humidity.
  - 각 변수에 대해 ±1·±2시간 값을 만든다.
  - 각 변수의 그날 주간(cos z > 0.05) 평균·최소·최대·표준편차를 만든다.
  - 전날 주간 평균 5개를 만든다: wa/wb 운량, wa/wb 강설, 강수확률. 전날 예보는 D-2에 발행된 것이다.
  - cs_ab / cos z를 추가한다.
  - 모든 피처는 대상일 전날 17시 이전에 발행된 예보만 쓴다.
  - 근거: 11/09 12개월 롤링 시험에서 −1.60%, 12개월 중 7개월 개선.

## 시험 조건

- 학습: 2023-06-01 01:00 ~ 2025-02-28 00:00. cov ≥ 0.3, cos z_max > 0.
- 평가: HOLDOUT 3개월. 253곳이 모두 가동 중이다.
- 지표: README 잠정 그룹 벌점 Σ 0.1·SMP·k·|예측 − 실적|이다. 예측은 cf × 가동용량으로 계산하며, D05 HOLD이고 official_S=null이다.

## 판정 규칙 (한 번만 본다)
