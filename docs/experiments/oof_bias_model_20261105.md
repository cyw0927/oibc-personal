# #1314 예보 시점 및 시간 분리 오차 보정 실험

## 예보 수신 근거

공식 제공 README의 정의: 목표일 전날 10시·17시 발행 예보를 제공하며 전날 17시 예측에 둘 다 사용할 수 있다. 데이터 계약 `history/v1/feature_availability_report.md`는 원본에 실제 `received_at`, 발행 및 가용 timestamp 열이 없다고 기록한다. 로컬의 안전 분리 WA/WB parquet 스키마에서도 관측소·round·대상 ts·변수는 있으나 수신 timestamp를 찾지 못했다. 따라서 **대회 제공 계약상 사용 가능**과 **실제 운영 수신 지연 검증 불가**는 별개의 결론이다. 실제 수신 시각을 추정해 증명한 것은 아니다.

## 기존 #1314 진단

기존 OOF의 README 잠정 그룹 벌점 중 11~15시가 JUL 79.79%, OCT 86.04%, JAN 88.10%, FEB 85.61%다. 실제 대비 SMP×k 가중 순오차는 JUL -8.05%, OCT +1.47%, JAN +5.42%, FEB +1.52%다. 음수는 과소, 양수는 과대. 7월 일부 발전소 코호트는 20MW×2 조건을 충족하지 않는다. 이는 상관 및 사후 진단이지 구름·계절이 원인이라는 증거는 아니다. 태양량이 큰 시간대이며 11~15시에 k=3이어서 비용이 집중된다는 점은 구조상 사실이다.

## 실행 전 확정 실험

기존 #1314의 시간별 그룹 예측을 기준으로, **이전 fold에서 발생한 OOF 오차만** 따로 학습하는 2단계 Ridge 보정기를 만든다. JUL/OCT 두 fold를 보정기 학습에 사용해 JAN을 예측하고, FEB는 JUL/OCT/JAN OOF까지 사용한다. 모든 학습 시각이 대상 fold의 시작 및 고정 cutoff 이전임을 강제한다. 입력은 OOF 예측/용량, 예보·태양고도·달력·그룹이다. 정답은 실제−예측을 용량으로 나눈 과거 OOF 오차이며, 해당 target fold의 실제 값은 오직 평가에만 사용한다. 학습 때 과거 SMP×k를 가중치로 쓰되 미래 SMP·미래 실적·발전량 lag는 입력하지 않는다. 중복 방지, 음수 방지, 실제·가격·시각 일치, 별도 벌점 재계산을 확인한다. 모델/정규화는 학습 fold에만 적합한다. 비율 탐색은 하지 않는다.

이전에 APR→AUG 및 JUL→OCT에서 대리 모델 하나를 이용한 별도 잔차 실험은 실패했으나, 본 실험은 실제 #1314 OOF 두 계절 이상으로 보정기를 학습하고 253개소 JAN/FEB를 고정 평가하는 별도 실험이다. OOF 중 JUL/OCT는 224/252개소 부분 코호트이고, JAN/FEB는 기존 v2 설정 재학습이므로 원본 v2와 완전 일치 미검증. 모두 이미 반복한 DEV이고 사후 진단을 바탕으로 설계했으므로 독립 테스트가 아니다. 겨울 그룹 특성 파일은 과거 생성 중 잠금 행과 섞인 row group에 접근했을 가능성이 있으나 이번 실행에는 잠금 행·원본 row group을 읽지 않는다. 모델 채택 및 공식 점수 확정은 금지. README 잠정, D05 HOLD, official_S=null. 데이터·파생물 Git 금지.

## 사후 안전장치 진단

1차 실행 후 1월 가중 순오차가 +45.46%로 커져 보정값 폭주를 확인했다. 이에 결과를 본 뒤 추가로 시간당 보정 폭을 기존 그룹 용량의 ±10%로 제한하는 안전장치 하나를 진단한다. 기존 0.4:0.6 예측의 결합 비율은 바꾸지 않는다. 이 한도는 최적값이 아니며 안전장치의 탐색적 예시다. 같은 평가 결과를 본 뒤 추가했으므로 점수가 개선되어도 독립 검증이나 제출 근거로 삼지 않는다. 야간 기존 예측 0은 유지하고 0 아래로 떨어지지 않게 한다.
