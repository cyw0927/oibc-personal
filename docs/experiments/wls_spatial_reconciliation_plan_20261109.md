# #1314 공간 계층 예측 동시 조정 계획

Yang et al. (2017) geographical hierarchy의 예측 계층을 오차 공분산 기반 가중최소제곱으로 일치시키는 원리와 Di Fonzo & Girolimetto (2023)의 비음수 조건을 참고한다. 이 실험은 **시공간 전체 논문 재현이 아니라, 시각별 발전소→G1/G2 공간 계층에만 적용한 대각 오차분산 WLS 근사**다. 공분산의 비대각 항과 일별·시간별 합계 동시 조정은 구현하지 않는다. 가중치·배합비를 평가 결과로 탐색하지 않는다.

발전소의 FS2+L1 OOF 개별 예측과 #1314의 독립 그룹 직접 예측을 상하위 원예측으로 사용한다. 과거 OOF 실적−예측의 각 발전소 분산과 각 그룹 합계 실적−독립 그룹 예측의 분산을 각각 계산한다. 과거에 없던 발전소 분산은 같은 그룹 발전소들의 용량 정규화 분산 중앙값×해당 발전소 용량²로 대체하고 0 분산에는 작은 양의 수치 하한을 둔다. 서로 다른 발전소의 오차 상관과 편향은 대각분산에서 표현하지 못한다.

매 그룹·시각에 발전소 조정값을 0 이상으로 제한하고, 발전소별 예측에서의 제곱 변경량/발전소 오차분산의 합과 조정된 발전소 합계와 그룹 원예측 차이의 제곱/그룹 오차분산을 최소화한다. 조정된 발전소 합이 조정 그룹 예측이므로 양쪽이 동시에 바뀔 수 있다. 활성집합으로 해를 구하고 합성 사례는 별도 수치 최적화와 대조한다.

JAN 평가에는 OCT 과거 OOF만, FEB 평가에는 OCT와 JAN 과거 OOF만 사용한다. 동일 발전소·시각·실적·SMP·k·기존 #990 그룹을 사용해 #1314 40:60 기준과 비교하며 동일 기준식으로 따로 벌점을 계산한다. 훈련/평가 시각 분리, 키 및 그룹별 실적·원예측 합계·비음수·합산 일치를 확인한다. 전량 row group 메타데이터가 잠금 이전임을 확인한 파일만 읽는다. 기존 겨울 직접 그룹 예측은 안전 전처리 여부가 과거에 입증되지 않았고 원본 v2와 대조되지 않은 재학습 결과, 예보 실제 수신시각 미확인, 반복된 DEV다. 수치는 README 잠정(D05 HOLD), official_S=null이며 대회 파생물 Git 금지.
